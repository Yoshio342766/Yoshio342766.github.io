# ドライブの記録

ドライブ・お出かけで立ち寄ったスポットを、地図や一覧で振り返るための個人用 Web ページです。
GitHub Pages（github.io）で公開しています。サーバー処理は不要で、HTML / CSS / JavaScript のみで動作します。

## 機能

| ページ | ファイル | 内容 |
|---|---|---|
| メニュー | `index.html` | トップページ。「マップ（ピン）」「検索」へのリンクを表示 |
| マップ（ピン） | `treeview.html` | 年・日付ごとのツリー表示。リンク先の地図ページ（`data/*.html`）を別タブで開く |
| 検索 | `search.html` | 立ち寄りスポットのキーワード検索・日付順の並び替え・「もっと見る」表示 |

### 検索ページの仕様

- **キーワード検索**: 日付・場所／施設名・備考を対象にします。半角／全角スペースで区切ると AND 検索になります。大文字小文字は区別しません。
- **並び替え**: 日付の降順（既定）／昇順を切り替えられます。同一日付の場合は、データの SEQ_No（7 列目）を第 2 キーとして、日付と同じ向きで並べます。
- **表示件数**: 初期表示は直近 25 件です。下部の「もっと見る（残り N 件）」ボタンで追加表示します。
- **件数表示**: キーワード入力時は「全 N 件中、該当 M 件（うち X 件を表示しています）。」のように該当件数を表示します。
- **地図表示**: 各行の「地図を表示」ボタンで、緯度・経度から Google マップを別タブで開きます。

## フォルダ構成

```
/
├─ index.html          メニュー
├─ treeview.html       マップ（ピン）のツリー表示
├─ search.html         検索ページ
├─ css/
│   ├─ index.css
│   ├─ treeview.css
│   └─ search.css
├─ js/
│   └─ search.js       検索・並び替え・もっと見る処理
├─ json/
│   └─ search.json     検索ページの設定ファイル
├─ data/
│   ├─ Geocode_places2.tsv   立ち寄りスポットのデータ
│   └─ *.html                地図ページ（全体・日付別）
└─ image/
    └─ index_background.jpg  メニューの背景画像
```

## データファイル（`data/Geocode_places2.tsv`）

ヘッダーなし・タブ区切り（TSV）で、1 行 1 スポットです。`search.js` は次の列を使用します。

| 列 | 内容 | 例 |
|---|---|---|
| 1 | 日付 | `2016-10-15` |
| 2 | 場所・施設名 | `道の駅 やいた` |
| 3 | 備考 | `自：09:43` |
| 4 | `[緯度,経度]`（検索ページでは未使用） | `[38.06,140.78]` |
| 5 | 緯度 | `38.0621626` |
| 6 | 経度 | `140.7883442` |
| 7 | SEQ_No（同一日付内の順序） | `1` |

- 文字コードは UTF-8 です。
- 緯度・経度が空の行は、地図ボタンの代わりに「-」を表示します。

## 設定ファイル（`json/search.json`）

検索ページの表示件数を設定します。

```json
{
    "initialDisplayCount": 25,
    "loadMoreCount": 25
}
```

| キー | 説明 | 既定値 |
|---|---|---|
| `initialDisplayCount` | 初期表示件数 | 25 |
| `loadMoreCount` | 「もっと見る」1 回で追加する件数（省略時は `initialDisplayCount` と同じ） | 25 |

ファイルが無い場合や値が不正な場合は、25 件で動作します。

## 更新方法

### スポットを追加する

1. `data/Geocode_places2.tsv` に行を追加します（上記の列構成、UTF-8）。
2. 同じ日付に複数のスポットがある場合は、SEQ_No に訪問順の連番を入れます。
3. 保存して GitHub へ push します。

### 日付別の地図ページを追加する

1. `data/` に `YYYY-MM-DD_地名.html` を追加します。
2. `treeview.html` の該当する年の `<ul>` 内に、次の形式でリンクを追加します。

```html
<li class="file"><a target="_blank" rel="noopener noreferrer"
    href="data/2026-06-19_軽井沢.html">🗾2026-06-19_軽井沢</a></li>
```

## ローカルでの確認

`file://` で直接開くと、ブラウザの制限で `fetch` によるデータ読み込みができない場合があります。
ローカルで確認するときは、簡易サーバーを使用してください。

```bash
python -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

## 使用技術

- HTML / CSS / JavaScript（ライブラリ・フレームワークなし）
- GitHub Pages による公開
- 地図表示は Google マップの URL スキームを使用
