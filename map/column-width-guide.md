# 検索ページ 明細テーブルの列幅指定ガイド

ドライブの足跡 検索ページ（`search.html` / `search.js` / `search.css`）で、明細テーブルの列幅を次のように指定する方法をまとめたものです。

- 1列目（No）、2列目（日付）：相対単位（em）の固定幅
- 3列目（場所・施設名）、4列目（備考）：残り幅を **80% : 20%**（または任意の比率）で配分
- 3・4列目：文字があふれた場合は「…」で省略表示（維持）

---

## 1. 結論

CSS の `calc()` と `%` を組み合わせた列幅指定（例：`width: calc((100% - 10em) * 0.8)`）は、ブラウザが無効（`auto`）として扱うため、期待どおりに動作しません。3・4列目が均等幅になってしまいます。

そこで、**表の構造で配分する方法**を採用しました。

---

## 2. 仕組み

`table-layout: fixed` のテーブルでは、幅指定のない列が、残り幅を**均等に**分け合います。

これを利用して、次のように構成します。

1. `<colgroup>` で、1・2列目に固定幅を指定する
2. 幅指定のない列を複数用意する（80:20 の場合は5列）
3. 3列目のセルを `colspan="4"`（4列分）、4列目のセルを1列分にする

残り幅が5等分され、3列目が4つ分（80%）、4列目が1つ分（20%）を使うことになります。

```
|  No  | 日付 |      場所・施設名（4列分）      | 備考（1列分） |
| 3em  | 7em  | [ 1 ][ 2 ][ 3 ][ 4 ]（残り幅の均等分）| [ 5 ]        |
```

画面上の見た目は、これまでどおり4列のままです。

---

## 3. 80:20 版のコード

### search.html（テーブル部分）

```html
<table>
    <!-- 列幅: 1,2列目は固定幅、残りの5列(幅指定なし)は均等配分。
         3列目は4列分(colspan=4)、4列目は1列分を使うため 80% : 20% になる -->
    <colgroup>
        <col style="width: 3.0em;">
        <col style="width: 7.0em;">
        <col span="5">
    </colgroup>
    <thead>
        <tr>
            <th>No</th>
            <th>日　付</th>
            <th colspan="4">場所・施設名（Map link）</th>
            <th>備　考</th>
        </tr>
    </thead>
    <tbody id="resultBody">
        <!-- JavaScriptで結果を挿入 -->
    </tbody>
</table>
```

### search.js（変更箇所）

「該当なし」行の `colspan`：

```js
tbody.innerHTML = `<tr><td colspan="7" class="no-result">該当するデータが見つかりません。</td></tr>`;
```

場所・施設名セルの生成部分：

```js
// 場所・施設名（緯度・経度があればクリックで地図を表示するリンクにする）
const nameTd = document.createElement('td');
nameTd.colSpan = 4; // 列幅配分のため4列分を使用（search.html の colgroup 参照）
nameTd.title = item.name;
```

### search.css（関連部分）

列幅の指定は HTML 側で行うため、CSS には説明コメントのみを残します。「…」による省略表示の指定はそのまま使います。

```css
/* 列幅の指定は search.html の <colgroup> で行う
   1, 2列目: 相対単位(em)の固定幅
   3, 4列目: 残り幅を 80% : 20% で配分
   （3列目は colspan=4、4列目は colspan なしで、幅指定のない5列を均等配分させている） */

/* 3列目（場所・施設名）と4列目（備考）を「…」で省略する */
td:nth-child(3),
td:nth-child(4) {
    white-space: nowrap;      /* 折り返さない */
    overflow: hidden;         /* はみ出た部分を隠す */
    text-overflow: ellipsis;  /* 隠れた部分を「…」で表示 */
}
```

## 4. 75:25 版への変更点

80:20 版から、次の箇所だけを変更します。

| ファイル | 変更箇所 | 80:20 | 75:25 |
|---|---|---|---|
| `search.html` | `<col span>` | `5` | `4` |
| `search.html` | 3列目ヘッダー `<th colspan>` | `4` | `3` |
| `search.js` | `nameTd.colSpan` | `4` | `3` |
| `search.js` | 「該当なし」行の `colspan` | `7` | `6` |
| `search.css` | 説明コメントの比率のみ | 80:20 | 75:25 |

75:25 版のコード全体は、`ratio_75_25` フォルダ内の3ファイルにあります。

---

## 5. 比率を変える場合の考え方

3列目 : 4列目 = **a : b** にしたいときは、次のように設定します。

| 設定箇所 | 値 |
|---|---|
| `<col span>` の数 | `a + b` |
| 3列目の `colspan`（HTML の `th` と JS の `nameTd.colSpan`） | `a` |
| 4列目の `colspan` | 指定しない（`b` 列分は自動） |
| 「該当なし」行の `colspan` | `2 + a + b` |

### 例

| 比率 | `<col span>` | 3列目の `colspan` | 「該当なし」行の `colspan` |
|---|---|---|---|
| 80:20（a=4, b=1） | 5 | 4 | 7 |
| 75:25（a=3, b=1） | 4 | 3 | 6 |
| 70:30（a=7, b=3） | 10 | 7 | 12 |

※ 4列目に `colspan` を指定しない場合は `b = 1` となります。`b` が 2 以上のときは、4列目のセル（HTML の `th` と JS の備考セル）にも `colspan="b"` を指定してください。この場合、「該当なし」行の `colspan` は `2 + a + b` のままです。

---

## 6. 注意点

- 1・2列目の幅は、`<col style="width: ...">` の値で変更できます。変更すると、3・4列目は残り幅に自動で追従します。
- テーブルには `table-layout: fixed` と `min-width` の指定があります。画面幅がこの最小幅を下回ると、テーブルのラッパー（`.table-wrapper`）が横スクロールになります。
- 「…」による省略表示は、3・4列目の `overflow: hidden` / `text-overflow: ellipsis` で実現しています。`colspan` を使っても動作に影響はありません（動作確認済み）。
